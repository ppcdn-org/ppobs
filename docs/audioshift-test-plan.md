# AudioShift 变声功能测试方案

> 面向人工执行的测试计划。覆盖 P0（音高变换滤镜）与 P1（效果层 + 前端声音模板）。
> 设计依据见 `docs/audioshift-design.md`，本文件只描述"怎么测、期望是什么、结果记哪"。
> 每个用例给一个编号（`AS-xx`），执行时在"结果"列填 `通过 / 不通过 / 跳过`，不通过时
> 在"备注"里写现象、日志片段、复现步骤。

## 1. 环境与前置条件

| 项 | 要求 |
|---|---|
| 平台 | Windows x64（当前 P0/P1 只承诺 Windows） |
| 构建环境 | 见 `BUILD_NOTE.md`（VS 2026 / Windows SDK / `D:\program\CMake`） |
| 可执行产物 | `build_x64\rundir\RelWithDebInfo\bin\64bit\obs64.exe` |
| 插件产物 | `build_x64\rundir\RelWithDebInfo\obs-plugins\64bit\obs-filters.dll` |
| 音频设备 | 至少一个麦克风输入（`wasapi_input_capture` 枚举得到） |
| 监听方式 | 建议配一副耳机，用 OBS "监听并输出" 或系统"侦听此设备"做耳返，便于评估延迟/爆音 |

### 1.1 先构建（源码有改动时）

```bat
build_configure.bat
build_build.bat
```

只改了前端 / 插件时可用增量脚本（注意本仓库脚本里的路径是构建机路径，按实际调整）：

```bat
build_build_frontend.bat
```

构建后确认 `obs-filters.dll` 与 `obs64.exe` 的时间戳是最新的；`rundir` 若被占用导致
copy 失败，先关掉正在运行的 `obs64.exe` 再重试。

### 1.2 启动

```
build_x64\rundir\RelWithDebInfo\bin\64bit\obs64.exe
```

启动后打开 **帮助 → 日志文件 → 查看当前日志**，测试期间保持可查看，部分用例要核对日志。

## 3. 基础挂载与属性（P0）

操作入口：**来源列表**里右键麦克风源 → **滤镜** → 左下角 **+** → 选 **"Voice Changer (AudioShift)"**。

| 编号 | 步骤 | 期望 | 结果 | 备注 |
|---|---|---|---|---|
| AS-01 | 打开滤镜列表 | 存在 `Voice Changer (AudioShift)` 一项 | | |
| AS-02 | 挂到麦克风，默认（自定义 0 半音、效果=无）说话 | 声音与未挂滤镜基本一致，无爆音/无声/卡顿 | | |
| AS-03 | 打开该滤镜属性，观察字段 | 有 `Preset`、`Pitch Shift (semitones)`、`Estimated added latency`、`Effect Layer` | | |
| AS-04 | 属性页 `Estimated added latency` | 出现后显示如 "…~32 ms" 级别数值（非 "not yet measured" 除非刚挂上还没有音频流过） | | |

## 4. 音高变换（P0）

| 编号 | 步骤 | 期望 | 结果 | 备注 |
|---|---|---|---|---|
| AS-05 | Preset=男声变女声（+9） | 明显升调、卡通感（不承诺自然），语速不变 | | |
| AS-06 | Preset=女声变男声（-8） | 明显降调、低沉 | | |
| AS-07 | Preset=童声（+12） | 尖细"花栗鼠"效果 | | |

| AS-11 | 选"自定义"时看滑块 | 滑块可编辑 | | |
| AS-12 | 直播/监听中热切换预设、来回拖滑块 | 有短暂过渡但不出现爆音/长静音/持续怪声 | | |

## 5. 效果层（P1，`Effect Layer` 下拉）

三者互斥：无 / 机器人 / 空灵回声。选中某层时，只有该层参数可编辑。

### 5.1 机器人

| 编号 | 步骤 | 期望 | 结果 | 备注 |
|---|---|---|---|---|
| AS-13 | Effect=机器人，`Robot Mix`=0% | 与"无"一致（直通） | | |
| AS-14 | `Robot Mix`=100%，`Robot Carrier` 在 20→100 Hz 扫 | 出现机械"电流/嗡嗡"机器音，频率越高调制越快越尖 | | |
| AS-15 | 机器人层下把 Mix 从 0→100% 来回拖 | 平滑过渡，不爆音 | | |

### 5.2 空灵回声

| 编号 | 步骤 | 期望 | 结果 | 备注 |
|---|---|---|---|---|
| AS-16 | Effect=空灵回声，Echo Mix=0% | 与"无"一致（直通） | | |
| AS-17 | 延迟从 30→400 ms 拖，反馈 40% | 回声间隔随延迟变化 | | |
| AS-18 | 反馈拉到 90%，长时间说话/大声输入 | 回声增多但**不失控、不硬削波爆音**（软限幅生效） | | |
| AS-19 | 在回声层切换延迟/反馈/混合参数 | 无静音缺口（参数变化不应把音频整段变哑） | | |

### 5.3 效果层切换

| 编号 | 步骤 | 期望 | 结果 | 备注 |
|---|---|---|---|---|
| AS-20 | 无→机器人→空灵回声→无 反复切换 | 不残留上一层的尾巴/怪声；切换瞬间可接受无长爆音 | | |
| AS-21 | 效果层与音高同时用（如 童声 + 回声） | 两者叠加生效 | | |

## 8. 声音模板（P1，前端滤镜链）

> **已移除**：设置页的声音模板下拉框已删除，本节（AS-28~AS-35）不再适用，无需执行。

操作入口：**设置 → 流 → 高级选项**，找到 **Voice Template / 声音模板** 下拉框。

> 关键实现说明：模板只会挂到 **麦克风输入源**（`wasapi_input_capture`），**不会**碰桌面/系统
> 音频捕获。模板链固定为 `AudioShift (Voice Template)` → `3-Band EQ (Voice Template)`
> → `Compressor (Voice Template)`。

| 编号 | 步骤 | 期望 | 结果 | 备注 |
|---|---|---|---|---|
| AS-28 | 设置页流标签的高级选项区 | 出现"声音模板"下拉，含 无/温柔男中音/甜美女高音/沉稳男低音 | | |
| AS-29 | 选"温柔男中音"→ 确定，打开麦克风源的滤镜列表 | 出现上述**三个**固定命名滤镜，**顺序**为 AudioShift 在最上（先处理）到 Compressor—以滤镜窗口实际顺序为准，音频依次经过变声→EQ→压缩 | | |
| AS-30 | 分别在三个模板间切换 | 麦克风源上仍是那三个滤镜（不重复新增），参数就地变化，切换时无爆音 | | |
| AS-31 | 切回"无" | 三个模板滤镜从麦克风源上被移除 | | |
| AS-32 | 选任一模板后，检查**桌面音频/系统音频**捕获源 | 其滤镜列表**不含**这三个模板滤镜（不受影响） | | |
| AS-33 | 选模板后重启 OBS | 模板选择保留，麦克风源上三个滤镜重新出现且参数正确 | | |
| AS-34 | 在麦克风源上手动再加一个 OBS 自带滤镜（如 Noise Suppression），再看模板链 | 手动滤镜与模板链共存，均未丢失 | | |
| AS-35 | 模板 + 手动挂"Voice Changer (AudioShift)"且自定义参数 | 两个 AudioShift 实例并存，互不干扰（说明模板用的是固定命名私有实例） | | |
| AS-36 | 模板链开启时耳返主观听感 | 半音 + EQ + 压缩组合效果可辨（"温柔/甜美/低沉"方向正确），无明显失真 | | |

> AS-29 顺序判定：OBS 滤镜窗口中列表**越靠下越先处理**。AudioShift 应在最下方（最先），
> Compressor 在上方（最后）。若顺序相反，记录为不通过。

## 12. 通过标准与风险提示

**通过标准（P0/P1 发布门槛建议）**

- AS-A1/A2/A3 全部通过。
- P0 音高段（AS-05~AS-12）无"不通过"。
- 效果层（AS-13~AS-21）无 crash、无硬削波爆音（AS-18 必须通过）。
- 声音模板（AS-28~AS-35）无"不通过"，尤其是 AS-32（不误挂桌面音频）与 AS-33（持久化）。
- 稳定性段（AS-37~AS-42）无 crash、无持续漏音。
- 主观音质（AS-40、AS-36）记录但按"可接受度"评估，不强制门限。

**已知风险 / 注意**

- 音高与效果层的默认/预设数值是**调研估值、未真人试听调优**，本测试若发现明显不自然，
  属预期内的"待调参"，记录具体值供后续微调（见设计文档 §6.1/§8.2/§14）。
- 延迟实测为算法内数值，真实语音可能不同（设计文档 §8.2）。
- 本测试计划在编写环境**未运行过 `obs64.exe`**：上述用例是待执行清单，其中"期望"来自
  代码与设计推导，若与实机行为不符，以实机为准并回填。
- 构建脚本里的路径可能是构建机路径，执行前按本机实际改。
